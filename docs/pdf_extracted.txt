Marks
Presentation-I (10) and Presentation-II (10) are already evaluated. The final
10 marks cover Presentation-III (UI demo): 5 marks and the Project
Report: 5 marks.
A. GitHub Setup
1
Create a GitHub account if you do not have one.
2
Create a public repository named DBMS-Course-Project.
3
Inside it, create four folders: Presentation-I, Presentation-II, Presentation-III, Project-Report.
4
Add a README.md with your name, roll number, project title and a one-line description.
5
Make regular commits; the commit history will be checked. Share the repository link as instructed
by your faculty.
B. Already Presented: Upload Required

Presentation-I: your Problem Description PPT/PDF.

Presentation-II: your PPT/PDF, ER diagram image, a .sql file with all commands (database and
table creation, insertion, SELECT statements), and the solution to the query given to you during
Presentation-II.
These should be in the repository by 10 October 2026. They carry no new marks but are required for
your final submission to be complete.
C. Presentation-III: User Interface (5 marks)
Present a working UI connected to your MySQL database that supports:

Insertion of records

Deletion of records

Viewing of records
Demonstrate each operation live, showing the change reflected in the database.

E. General Rules

The project report must be uploaded to GitHub by 10 October 2026. This is a hard deadline; late
submissions will not be accepted. The Presentation-III demo must be given on your allotted day.

Be present on your allotted day between 9:00 am and 5:00 pm, as per the merged list (see
schedule). Absence without prior permission will result in zero marks.

You must be able to explain every part of your project and answer questions on it.

Work must be original. Copied projects will receive zero.
